# Security policy

## Supported versions

The latest release on the default branch is the supported version. Older copies should be updated after a security fix is announced.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Joynal Abdin through the contact channel listed at [devjoynal.com](https://devjoynal.com). Do not publish passwords, API keys, database credentials, private URLs or an exploit in a public GitHub issue.

When possible, include the plugin version, WordPress and WooCommerce versions, a concise reproduction path, and a redacted log or screenshot. Remove personal customer information before sending any report.
